# Self-hosted fonts

Outfit (300–700), JetBrains Mono (400–500), Syne (400–800), and Fraunces
(normal 300–700, italic 300) are served from this origin. The WOFF2 files retain
all subsets returned by the Google Fonts CSS API, including Latin extended
characters. CSS retains `font-display: swap` and the original Unicode ranges.
Fraunces retains its optical-size range of 9–144.

Downloaded on 2026-10-17 from:

```
https://fonts.googleapis.com/css2?family=Outfit:wght@300..700&family=JetBrains+Mono:wght@400..500&family=Syne:wght@400..800&family=Fraunces:ital,opsz,wght@0,9..144,300..700;1,9..144,300&display=swap
```

This URL is provenance only; the browser loads `/fonts/fonts.css` and local
WOFF2 files. Original download URLs are recorded in `sources.json`.

notice and license are included in the corresponding `*-OFL.txt` file, sourced
from `https://github.com/google/fonts/tree/main/ofl/<family>`.
